# Two Steps Studio Desktop - Release Notes

## Wersja 1.0.0 (2 sierpnia 2026)

### Pierwsza oficjalna wersja

**Nowe funkcje:**
- Pełna integracja z systemem Windows 10/11
- Professjonalny instalator NSIS z konfiguracją użytkownika
- Wersja portable dla użytkowników przenośnych
- Automatyczne aktualizacje w tle
- Natywne powiadomienia systemowe Windows
- Obsługa trybu offline z automatyczną synchronizacją
- System tray z menu kontekstowym
- Obsługa deep links (tss://)
- Szyfrowanie sesji użytkownika (AES-256-CBC)
- Kompletny system logowania błędów
- Minimizowanie do tray
- Kontrola okna z poziomu aplikacji
- Restart aplikacji

**Ulepszenia:**
- Zoptymalizowany czas uruchamiania
- Lepsze zarządzanie pamięcią
- Wzmocnione zabezpieczenia (sandbox, walidacja IPC)
- Lepsza obsługa błędów
- Ulepszona integracja z systemem Windows

**Poprawki błędów:**
- Naprawiono wycieki pamięci przy zamykaniu okna
- Naprawiono problemy z synchronizacją offline
- Naprawiono błędy w obsłudze aktualizacji
- Naprawiono problemy z tray na Windows 11

**Wymagania systemowe:**
- System operacyjny: Windows 10 lub nowszy (64-bit)
- Procesor: Intel Core i3 lub równoważny
- Pamięć RAM: 4 GB minimum (8 GB zalecane)
- Miejsce na dysku: 500 MB na instalację
- Połączenie internetowe: wymagane do synchronizacji

**Znane problemy:**
- Brak obsługi systemu Windows 7 i starszych
- Aktualizacje wymagają uprawnień administratora

**Planowane funkcje:**
- Discord Rich Presence
- Integracja z systemem plików
- Optymalizacja czasu uruchamiania
- Dodatkowe opcje personalizacji

## Instrukcje aktualizacji

### Z wersji 0.x do 1.0.0
1. Pobierz instalator wersji 1.0.0
2. Uruchom instalator
3. Wybierz "Aktualizuj" gdy zostaniesz zapytany
4. Twoje ustawienia i sesja zostaną zachowane

### Automatyczna aktualizacja
Aplikacja automatycznie wykryje dostępność aktualizacji i poinformuje Cię o możliwości pobrania. Aktualizacja zostanie zainstalowana po ponownym uruchomieniu aplikacji.

## Raportowanie błędów

Jeśli napotkałeś błąd, prosimy o:
1. Sprawdź logi aplikacji (Ustawienia > Diagnostyka > Eksportuj logi)
2. Wyślij raport na: support@twostepsstudio.com
3. Dołącz opis problemu i kroki do jego reprodukcji
